## 🌐 **Farsi Menu Names:**

### **Automatic Detection:**
The theme automatically detects RTL/Persian language and shows:

| English | Farsi |
|---------|--------|
| Home | خانه |
| Music | موزیک |
| Albums | آلبوم‌ها |
| Blog | وبلاگ |
| About | درباره من |
| Contact | تماس با من |

### **Smart Detection:**
- Detects `is_rtl()` WordPress function
- Checks for Persian locale (`fa_IR`, `fa_AF`)
- Arabic locale support (`ar`)
- Manual RTL toggle support
