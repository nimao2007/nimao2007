# Nima Oladi - Personal Website

A modern, responsive personal website with full RTL support and beautiful Persian typography.

## 🎨 Features

### RTL Support
- **Right-to-Left Layout**: Complete support for Persian/Farsi text direction
- **Modern Persian Font**: Uses Vazirmatn font for beautiful Persian typography
- **Responsive Design**: Works perfectly on all screen sizes
- **RTL Animations**: All animations and transitions are RTL-compatible

### Modern Design
- **Clean & Modern**: Contemporary design with smooth animations
- **Dark/Light Theme**: Toggle between different themes
- **Mobile First**: Optimized for mobile devices
- **Fast Loading**: Optimized for performance

### Sections
- **Home**: Introduction with call-to-action buttons
- **About**: Personal information and statistics
- **Skills**: Technical skills with animations
- **Services**: Services offered with modal details
- **Portfolio**: Project showcase with slider
- **Contact**: Contact form with validation

## 🚀 Technologies Used

- **HTML5**: Modern semantic markup
- **CSS3**: Advanced styling with Flexbox and Grid
- **Vanilla JavaScript**: Interactive functionality
- **Swiper.js**: Portfolio slider
- **ScrollReveal**: Scroll animations
- **Font Awesome**: Beautiful icons
- **Vazirmatn Font**: Modern Persian typography

## 📁 File Structure

```
├── index.html          # Main HTML file
├── styles.css          # Main stylesheet with RTL support
├── script.js           # JavaScript functionality
├── assets/
│   ├── img/           # Images and graphics
│   └── pdf/           # PDF files (CV, etc.)
├── README.md          # English documentation
└── README-fa.md       # Persian documentation
```

## 🛠️ Setup & Installation

1. Clone or download the repository
2. Open `index.html` in a web browser
3. For development, use a local server:

```bash
# Simple HTTP server
python -m http.server 8000
# or
npx serve .
```

## 🎨 Customization

### Personal Information
Edit `index.html` to change:
- Name and title
- About text
- Social media links
- Contact information

### Colors & Theme
Modify CSS variables in `styles.css`:
```css
:root {
  --first-color: hsl(207, 65%, 65%);
  --title-color: hsl(207, 4%, 16%);
  --text-color: hsl(207, 4%, 28%);
}
```

### Images
Replace images in `assets/img/` with your own photos and graphics.

## 🌍 RTL Implementation

This website includes comprehensive RTL support:
