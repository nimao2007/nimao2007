# وب‌سایت شخصی نیما اولادی

وب‌سایت شخصی مدرن و ریسپانسیو با پشتیبانی کامل از RTL و فونت زیبای فارسی

## ویژگی‌ها

### 🎨 طراحی و ظاهر
- **RTL (راست به چپ)**: پشتیبانی کامل از راست‌چینی فارسی
- **فونت مدرن**: استفاده از فونت Vazirmatn برای نمایش زیبای متون فارسی
- **طراحی ریسپانسیو**: سازگار با تمام اندازه‌های صفحه‌نمایش
- **انیمیشن‌های نرم**: تحولات نرم و انیمیشن‌های جذاب
- **تم تیره و روشن**: قابلیت تغییر بین تم‌های مختلف

### 🚀 عملکرد
- **سرعت بالا**: بهینه‌سازی شده برای بارگذاری سریع
- **SEO دوستانه**: مهیا برای موتورهای جستجو
- **کراس براوزری**: سازگار با تمام مرورگرهای مدرن
- **PWA Ready**: آماده برای تبدیل به اپلیکیشن وب

### 📱 بخش‌ها
- **صفحه اصلی**: معرفی و دکمه‌های دسترسی سریع
- **درباره من**: اطلاعات شخصی و آمار
- **مهارت‌ها**: نمایش تخصص‌ها با انیمیشن
- **خدمات**: معرفی خدمات ارائه شده
- **نمونه کارها**: نمایش پروژه‌های انجام شده
- **تماس**: فرم تماس با اعتبارسنجی

## فناوری‌های استفاده شده

- **HTML5**: ساختار مدرن صفحه
- **CSS3**: استایل‌دهی پیشرفته با Flexbox و Grid
- **JavaScript**: تعاملات پویا و انیمیشن‌ها
- **Swiper.js**: اسلایدر نمونه کارها
- **ScrollReveal**: انیمیشن‌های scroll
- **Font Awesome**: آیکون‌های زیبا

## نصب و راه‌اندازی

1. فایل‌ها را دانلود کنید
2. در یک وب سرور اجرا کنید
3. فایل `index.html` را باز کنید

```bash
# برای سرور محلی ساده
python -m http.server 8000
# یا
npx serve .
```

## سفارشی‌سازی

### تغییر اطلاعات شخصی
فایل `index.html` را ویرایش کنید و اطلاعات زیر را تغییر دهید:
- نام و عنوان
- متن‌های توضیحی
- لینک‌های شبکه‌های اجتماعی
- اطلاعات تماس

### تغییر رنگ‌ها
در فایل `styles.css`:
```css
:root {
  --first-color: hsl(207, 65%, 65%); /* رنگ اصلی */
  --title-color: hsl(207, 4%, 16%);  /* رنگ عناوین */
  --text-color: hsl(207, 4%, 28%);   /* رنگ متن */
}
```

### اضافه کردن تصاویر
تصاویر خود را در پوشه `assets/img/` قرار دهید و مسیرها را در HTML به‌روزرسانی کنید.
