# Artist Music Pro - Installation Guide

## Quick Start

### 1. Install the Theme
- Download the `artist-music-theme` folder
- Upload to your WordPress site at `/wp-content/themes/`
- Activate from `Appearance > Themes`

### 2. Initial Setup
1. **Go to Customizer**: `Appearance > Customize`
2. **Configure Hero Section**:
   - Hero Title: "به دنیای موسیقی من خوش آمدید" (Welcome to My Music World)
   - Hero Subtitle: "خواننده • ترانه‌سرا • هنرمند" (Singer • Songwriter • Artist)

3. **Set RTL Language**:
   - The theme automatically detects RTL languages
   - Manual toggle available in header

### 3. Add Your Music
1. **Go to Music > Add New**
2. **Add Track Details**:
   - Title (in Farsi/English)
   - Audio File URL
   - Album Name
   - Duration (e.g., "3:45")
   - Genre
   - Mark as Featured for homepage display

### 4. Configure Social Media
In Customizer > Social Media, add your URLs:
- Instagram
- YouTube
- Spotify
- SoundCloud
- Facebook
- Twitter

### 5. Farsi Font Features
- **Primary Font**: Vazirmatn (modern Persian font)
- **Automatic RTL**: Detects Persian/Arabic content
- **Number Support**: Both Western and Persian numerals
- **Proper Spacing**: Optimized for Persian typography
